# 알까기 ⚫

바둑판 위에서 내 알을 튕겨 상대 알을 판 밖으로 떨어뜨리는 게임. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 흑·백 6개씩. 흑이 먼저, 차례대로 자기 알 하나를 **뒤로 끌었다 놓아** 튕긴다 (새총처럼, 많이 끌수록 세게. 화살표 색이 초록 → 주황 → 빨강)
- 알은 미끄러지다 마찰로 멈추고, 알끼리는 당구공처럼 부딪힌다. 판 밖으로 나간 알은 떨어진다 (내 알도)
- 상대 알을 모두 떨어뜨리면 승리. 한 번에 양쪽 마지막 알이 다 떨어지면 튕긴 쪽이 진다
- **🤖 컴퓨터랑** (나는 흑): 쉬움 · 보통 · 어려움. 컴퓨터는 여러 방향·세기를 같은 물리로 끝까지 굴려 보고 가장 좋은 수를 고른다. 쉬울수록 덜 보고 손이 떨린다
- **👥 둘이서**: 한 화면에서 번갈아
- 컴퓨터를 이긴 횟수를 난이도별로 저장(`alkkagiWinsEasy` · `alkkagiWinsNormal` · `alkkagiWinsHard`), 로비 표시용은 합계 `alkkagiWins`
- M 소리

규칙·물리·컴퓨터 상대는 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력·소리는 `game.js`.
